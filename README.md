# CloudForge RideLab

A hands-on DevOps learning project based on a simulated ride-booking application.

## Project Goal

Build, test, containerise, and deploy a ride-booking application while learning DevOps engineering.

## Planned Features

- Passenger ride requests
- Driver ride acceptance
- Admin dashboard
- Simulated payments

## Technologies

- Linux and Bash
- Git and GitHub
- Python and FastAPI
- Docker
- GitHub Actions
- Google Cloud Run
- Terraform
